# Shared engineering baseline

## Procedure
1. Confirm task objective, scope, constraints, and required outcome.
2. Inspect the minimum relevant project context before deciding.
3. Follow project conventions and applicable requirements.
4. Make the smallest complete change; avoid unrelated refactoring.
5. Protect user changes, data, secrets, and external contracts.
6. Distinguish facts, assumptions, inferences, and unknowns.
7. Validate proportionately and report only checks actually performed.
8. State material limitations and unresolved risks.
Do not repeat the global instruction baseline in deliverables. Use this skill as a compact checklist, not as a reason to load unrelated specialist workflows.
